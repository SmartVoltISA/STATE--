# STATE--

## RU
Исследование состояния как набора свойств системы в определённый момент. Изучаются описание состояния, переходы, устойчивость, наблюдаемость и критерии изменения.

## EN
Research of state as a set of system properties at a given moment. Focus: state description, transitions, stability, observability and criteria for change.
